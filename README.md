# Price Recommendation Service (Тестовое задание ТОЛЬКООПТ)

Реализация алгоритма рекомендации цен на основе анализа предложений конкурентов.

## Стек
- Python 3.10+
- Только стандартные библиотеки (`asyncio`, `decimal`, `unittest`)

## Запуск примера
```bash
python starter.py
```

## Запуск тестов
```bash
python -m unittest starter.py
```
*(также поддерживается запуск через `pytest starter.py`)*
